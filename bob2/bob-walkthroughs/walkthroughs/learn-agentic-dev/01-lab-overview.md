# Agent-Supported Development with Bob

This lab provides a hands-on experience how Bob supports you in a variety of development tasks. You'll explore an unfamiliar web application, fix security issues and enhance the application with new features - all supported by Bob.

## Lab Overview

In this lab, you will:

1. **Onboard** to an unfamiliar code base.
2. Fix **vulnerabilities** in the application.
3. Create a **new feature** from scratch. 
4. Fix issues found during Bob's **code review**.
5. Use Bob's **literate programming** to quickly extend the application.
6. Use **bobshell** and see how Bob extends beyond its IDE.
