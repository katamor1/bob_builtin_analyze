# Java Upgrade Lab with Bob

Upgrading enterprise Java applications presents significant challenges — from JDK version migrations to runtime compatibility issues. Bob's intelligent Java Upgrade solution simplifies this journey by analyzing your codebase and creating secure, efficient upgrade paths tailored to your needs.

This step-by-step approach for Bob will allow you to easily have your code use the newest Java version.

## Lab Overview

In this lab, you will do and learn how to:

1. **Upgrade Java version from 1.8 to 21** in a simple Tinify API application
2. **Use Bob** for this type of modernization
3. **Create summary** of all performed actions
