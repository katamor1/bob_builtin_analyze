# This is Bob

Bob can adapt to different tasks and workflows with specialized modes that optimize his capabilities.

## What are Modes?

Modes are specialized configurations that tailor Bob's behavior to specific tasks:

1. **🏗️ Plan Mode** - For planning, designing, and strategizing before implementation
2. **💻 Code Mode** - For writing, modifying, or refactoring code across any language
3. **🛠️ Advanced Mode** - For complex coding tasks with enhanced capabilities
4. **❓ Ask Mode** - For explanations, documentation, and answers to technical questions

## How Modes Work

- **Task-Optimized** - Each mode is optimized for specific types of tasks
- **Different Capabilities** - Modes have different tool access and permissions
- **Easy Switching** - Change modes at any time based on your current needs
- **Customizable** - Tailor modes to your specific workflow and preferences

## When to Use Each Mode

- **Plan Mode** - When breaking down complex problems, creating technical specifications, or designing system architecture
- **Code Mode** - When implementing features, fixing bugs, or making code improvements
- **Advanced Mode** - When working on complex coding tasks that require enhanced capabilities
- **Ask Mode** - When you need explanations or answers without making code changes

## Pro Tips

- Switch modes based on the phase of your project
- Use Plan mode before starting complex implementations
- Create custom modes for specific projects or frameworks
- Combine modes for multi-stage tasks (start with Plan, implement in Code)
