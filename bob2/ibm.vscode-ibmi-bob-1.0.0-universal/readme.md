# IBM Bob Premium Package for i

**IBM Bob Premium Package for i** extends IBM Bob with AI capabilities tailored for IBM i application development. By providing Bob with access to your IBM i, it enables you to work more effectively across the entire application lifecycle. Bob can help generate & explain code, build and test projects, create documentation, and even modernize legacy applications.

📖 Check out the full documentation [here](https://bob.ibm.com/docs/ide/premium-packages/bob-for-i/bob-for-i-index)!

## Key Features

### Modes

Use specialized IBM i modes to tailor Bob's behavior for your specific IBM i tasks.

| Mode | Description |
|------|-------------|
| *IBM i Developer* | Explain, generate, compile, test, and document code on IBM i including RPG, CL, DDS, and COBOL. |
| *IBM i Database* | Generate, modernize, tune, and review SQL within Db2 for i. |

### Workspaces

Work with source code on your local PC or directly on IBM i (QSYS or IFS).

| Workspace | Description |
|-----------|-------------|
| *Local* | Work with files and directories in your local workspace |
| *Library List* | Work with libraries, objects, and members in your library list. |
| *Home Directory* | Work with stream files or directories in your user profile's home directory |

### Tools

Use IBM i specific tools to read & write to members or stream files, run CL commands, run SQL statements, and much more.

| Tool | Description |
|------|-------------|
| *Access to IBM i* | Read, write, and search on both the QSYS and IFS file systems on IBM i. |
| *Execute on IBM i* | Run CL commands, SQL statements, and PASE commands on IBM i. |
| *Build and Test* | Build and test your IBM i applications using source locally or directly on IBM i. |
| *Documentation Retrieval* | Search and fetch IBM i documentation, CL command references, and SQL examples. |

### Skills

Use IBM i specific skills to achieve consistent results for specialized tasks.

- **Programming**
    - *RPGLE*: RPGLE fundamentals, OPM to ILE conversion, fixed-format to free-format conversion, record level access to embedded SQL conversion, 
    - *CL*: CL fundamentals, programming patterns, and best practices.
    - *DDS*: DDS fundamentals and advanced concepts for physical files, logical files, display files, printer files.
- **Database**
    - *SQL*: SQL fundamentals, stored procedures, error handling, UDTFs, temporal tables, system catalogs for Db2 for i.
    - *Data Modeling*: Data model fundamentals for Db2 for i, CCSID/encoding concepts, DDL generation, and DDS-to-DDL migration.
    - *Performance*: Index strategy, SQL optimization, and performance analysis techniques.
    - *Security & Integrity*: Security best practices, journaling, and commitment control.

### Commands

Use IBM i specific slash commands to re-use pre-defined prompts that automate repetitive tasks.

| Command | Description |
|---------|-------------|
| *Database Visualization* | Generate and visualize entity relationship diagrams (ERDs) directly from schemas on IBM i. |
| *SQL Analysis & Review* | Analyze and review Db2 for i SQL queries for syntax errors, SQE query optimization, security best practices, performance optimizations, and etc. |

### Workflows

Use IBM i focused workflows to tackle complex use cases using a structured flow of agentic and non-agentic steps.

| Workflow | Description |
|----------|-------------|
| *Code Modernization* | Convert from OPM to ILE and fixed-format to free-format. |
| *Business Rules Extraction* | Generate a comprehensive markdown report with extracted business rules. |
| *Unit Testing* | Create unit test plan documents and then implement working test suites. |
| *SQL Index Strategy* | Identify and implement SQL indexing improvements on IBM i by analyzing Db2 performance data from Plan Cache Snapshots or Database Monitors, surfacing Maintained Temporary Indexes (MTIs), Index Advisor recommendations, and high-elapsed-time queries, then guiding interactive index creation, workload verification, and cleanup. |
